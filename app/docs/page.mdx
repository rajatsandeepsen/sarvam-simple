# Sarvam Simple

I'll help you use SarvamAI batch processing models in cloudflare workers (serverless).

Everything is fully crafted, just run simple shadcn cmd to get these code into your typescript project.

eg:
```bash
bunx shadcn@latest add rajatsandeepsen/sarvam-simple/<component-name>
```

## Simple API

API ported to run in any environment

- [Audio API](/docs/audio-api)
- [Vision API](/docs/vision-api)

## Simple Server

Hono server that can run inside a serverless platforms

- [Audio Server](/docs/audio-server)
- [Vision Server](/docs/vision-server)

## Webhook Server

Hono server with webhook callbacks and optional KV-based id mapping.

- [Audio Server Webhook](/docs/audio-server-webhook)
- [Vision Server Webhook](/docs/vision-server-webhook)
- [Vision Server Queue](/docs/vision-server-queue)
